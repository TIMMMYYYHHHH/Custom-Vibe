# CustomVibe

A static landing page for CustomVibe, a custom magnet making business with an in-browser magnet preview tool.

## Features

- Pink navigation and brand-forward landing page
- Image upload preview for custom magnet mockups
- Shape selector for rounded square, circle, and rectangle magnets
- Optional caption preview
- Pricing sections for R50 x1, R250 x6, and R400 x10
- Custom quote call to action for larger orders

## Deploying to Cloudflare Pages

This site is plain HTML, CSS, and JavaScript. In Cloudflare Pages, connect the GitHub repository and use these settings:

- Build command: leave blank
- Build output directory: `/`

## Local preview

Open `index.html` in a browser or run a simple static server:

```bash
python3 -m http.server 8000
```
